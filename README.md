# PestsControl

### Мы начали не с приложения, а с исследования сезонных биологических угроз Центральной России. Выяснили, что официальные службы публикуют качественные данные, а активность разных вредителей связана с различными измеримыми факторами. Одновременно выяснилось, что по одной погоде нельзя достоверно предсказывать появление вредителя. Поэтому мы отказались от идеи прогнозатора и разработали систему оценки сезонного риска. Она получает текущую погоду, применяет отдельные правила для каждого вида и объясняет пользователю, почему риск сейчас повышен и какие профилактические действия рекомендованы

## Оценка сезонного риска клещей и вредителей растений

---

Проект представляет собой образовательное веб-приложение для оценки сезонного риска активности клещей и вредителей растений на территории Центральной России.

Приложение получает актуальные погодные данные для выбранной пользователем территории и сопоставляет их с правилами сезонной активности конкретных биологических угроз.

На основании полученных данных система определяет один из четырех уровней сезонного риска:

- низкий;
- умеренный;
- повышенный;
- высокий.

Для каждой оценки система показывает:

- название угрозы;
- текущий уровень риска;
- факторы, повлиявшие на результат;
- краткое объяснение;
- профилактические рекомендации;
- источник, на основании которого сформированы правила оценки.

Проект не предназначен для точного прогнозирования фактического появления вредителя в конкретной точке.

Результат работы системы показывает, насколько текущие сезонные и погодные условия соответствуют известным условиям активности рассматриваемой угрозы.

---

## Основание для разработки

Проект является результатом предварительного исследования сезонных биологических угроз в Центральной России.

В ходе исследования установлено, что активность различных видов зависит от разных факторов.

Например:

- для иксодовых клещей значимы сезон и температура;
- для колорадского жука — температура почвы;
- для капустной тли — температура и влажность;
- для яблонной плодожорки — накопленная сумма эффективных температур.

Исследование также показало, что погодные условия позволяют оценивать период повышенного риска, но не позволяют достоверно утверждать о фактическом наличии конкретного вредителя.

Поэтому в проекте используется модель **оценки сезонного риска**, а не модель точного прогнозирования появления вредителей.

---

## Выявленная проблема

Обычному жителю Центральной России, владельцу дачного, садового или огородного участка сложно своевременно определить, какие сезонные биологические угрозы актуальны в данный момент для его региона и объекта интереса. Официальная информация существует, но распределена между различными санитарными и аграрными источниками, публикуется в разных форматах и требует самостоятельного поиска и интерпретации.

Обычному пользователю сложно самостоятельно определить, какие сезонные биологические угрозы актуальны в данный момент для его территории.

Информация существует в официальных источниках, однако:

- относится к различным областям;
- публикуется разными организациями;
- распределена по региональным ресурсам;
- представлена в разных форматах;
- требует самостоятельного поиска;
- требует специальных знаний для интерпретации погодных и сезонных факторов.

Пользователь может видеть текущую температуру, влажность и прогноз погоды, но без дополнительных знаний не может определить, что эти показатели означают с точки зрения активности конкретного вредителя.

---

## Предлагаемое решение

Автоматически оценивать соответствие текущих погодных и сезонных условий известным условиям активности конкретных биологических угроз и заранее информировать пользователя о повышенном риске.

Приложение должно автоматически выполнять следующую последовательность:

```text
Выбор территории
        ↓
Получение погодных данных
        ↓
Определение актуальных угроз
        ↓
Применение правил для каждой угрозы
        ↓
Определение уровня риска
        ↓
Объяснение результата
        ↓
Профилактические рекомендации
```

Таким образом, приложение преобразует профессиональные сведения о сезонных условиях активности вредителей и текущие погодные данные в понятный обычному пользователю индикатор риска.
